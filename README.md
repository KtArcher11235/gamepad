## Bom:
- 1 unsoldered Seeed XIAO RP2040
- 20x through-hole 1N4148 Diodes
- 16(+4)x MX-Style switches
- 16(+4)x white blank DSA keycaps
- 20x SK6812 MINI-E LEDs
- 4x M3x16mm screws
- 4x M3x5mx4mm heatset inserts
